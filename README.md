# collected-toolbox · 收藏索引

这是账号 **lsv5853** 的开源项目收藏索引，与主力号 zzz7491 的原创项目完全分开。
收藏的每个项目都已 fork 到本账号下（点「我的 fork」直达），原仓库链接用于查看上游更新。
收录标准：免费开源、近期有更新、真实有用。star 数为 2026-10-23 收录时快照。

维护规矩：发现好项目 → fork 到 lsv5853 → 在本文件对应分组加一行。fork 不会自动跟随上游更新，需要新版时在 fork 页面点 Sync fork。
